# Vegetable Store

A front-end website for a vegetable store. (Work in progress)

## Technologies

- HTML
- Tailwind CSS v4 + daisyUI
- JavaScript
- jQuery

## How to run

```bash
git clone https://github.com/ali113113/vegetable-store.git
cd vegetable-store
npm install
npm run dev:css
```

Then open `index.html` with a local server (for example, VS Code Live Server).
