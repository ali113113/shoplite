# shoplite

A front-end website for a shoplite. (Work in progress)

## Technologies

- HTML
- Tailwind CSS v4 + daisyUI
- JavaScript
- jQuery

## How to run

```bash
git clone https://github.com/ali113113/shoplite.git
cd shoplite
npm install
npm run dev:css
```

Then open `index.html` with a local server (for example, VS Code Live Server).
